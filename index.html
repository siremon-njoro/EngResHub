EngRes Hub support, privacy and account help

EngRes Hub helps teachers read, save, and download English teaching resources in one app. This page explains how the app works, how data is handled, how download tokens and ads work, and how users can request account deletion.

App Overview

Teacher resource library
R

Read in app

Published PDF resources are opened inside EngRes Hub so users can read without being sent to Google Drive or another external document viewer.

S

Save resources

Signed-in users can save useful resources to their library and return to them later from their account.

D

Download with tokens

Downloads use download tokens. Tokens may be granted by the admin or earned through rewarded ads when ads are available.

Access and Downloads

User type Can read resources Can save resources Can download files

A resource that has already been downloaded may be downloaded again within the app's re-download window without consuming another token, according to the rules shown in the app.

Download Tokens

Download tokens control file downloads. Before a download starts, the app may tell the user how many tokens will be used and whether a previous download is still inside the free re-download period.

  • Guests are asked to create or sign in to an account before downloading.
  • Signed-in users need enough tokens for the selected resource.
  • After a successful download, the app updates the remaining token balance.
  • Admins can grant tokens from the admin panel.

Ads

EngRes Hub may show banner ads, interstitial ads, and rewarded ads using Google Mobile Ads / AdMob.

  • Rewarded ads can contribute toward earning download tokens.
  • Non-rewarded ads may appear during normal app use.
  • Ads are provided by Google Mobile Ads, subject to Google's advertising policies and user/device settings.

Privacy Policy Summary

Full policy

EngRes Hub uses Firebase Authentication, Cloud Firestore, Firebase Storage, and Google Mobile Ads. The app may store account details, saved resources, opened resources, download records, token balances, rewarded ad progress, account settings, and account deletion requests.

Uploaded educational PDF resources are stored in Firebase Storage. Users read them inside the app, and signed-in users can download them to phone storage when they have enough download tokens.

EngRes Hub does not sell personal information. Data may be processed by Google services used to run the app, including Firebase and Google Mobile Ads.

Account Deletion

Deletion page

Users can request account deletion inside the app from Profile > Request Account Deletion. An external request page is also available for users who cannot access the app.

After a valid request is received, the account and related app data may be deleted or anonymized, including profile data, saved resources, download token records, download history, rewarded ad progress, and account activity, except where limited records must be retained for legal, security, fraud-prevention, or operational reasons.
