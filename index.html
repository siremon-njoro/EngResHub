Access and Downloads

A resource that has already been downloaded may be downloaded again within the app's re-download window without consuming another token, according to the rules shown in the app.

Download Tokens

Download tokens control file downloads. Before a download starts, the app may tell the user how many tokens will be used and whether a previous download is still inside the free re-download period.

  • Guests are asked to create or sign in to an account before downloading.
  • Signed-in users need enough tokens for the selected resource.
  • After a successful download, the app updates the remaining token balance.
  • Admins can grant tokens from the admin panel.

Ads

EngRes Hub may show banner ads, interstitial ads, and rewarded ads using Google Mobile Ads / AdMob.

  • Rewarded ads can contribute toward earning download tokens.
  • Non-rewarded ads may appear during normal app use.
  • Ads are provided by Google Mobile Ads, subject to Google's advertising policies and user/device settings.

Information we collect

  • Account information: full name, email address, Firebase user ID, role, account status, and account settings when a user creates an account.
  • Resource activity: saved resources, opened resources, download records, token usage, token balance, and rewarded ad progress.
  • Uploaded resources: admin-uploaded PDF teaching resources stored in Firebase Storage.
  • Advertising data: Google Mobile Ads / AdMob may process device identifiers, advertising identifiers, ad interactions, approximate device information, and diagnostics depending on settings and configuration.

How we use information

  • To create and manage user accounts.
  • To allow users to read published resources.
  • To let signed-in users save resources and download files.
  • To track download tokens, downloads, and rewarded ad progress.
  • To support account deletion requests.
  • To maintain app security, prevent misuse, and improve reliability.

Storage and third-party services

EngRes Hub uses Firebase Authentication, Cloud Firestore, Firebase Storage, and Google Mobile Ads. Account records, saved resources, download token records, resource activity, and deletion requests may be stored in Firebase. PDF resources are stored in Firebase Storage.

EngRes Hub does not sell users' personal information. Data may be processed by Google services used to run the app, including Firebase and Google Mobile Ads.

Security

We use Firebase and Google services that support encrypted network communication. We also use app, database, and storage rules to help limit access to user and admin data. No system is perfectly secure, but we aim to protect user information using reasonable technical and organizational measures.

Children's privacy

EngRes Hub is intended for teachers and education professionals, not as a child-directed app. If this changes, the privacy policy and app settings must be updated to comply with child privacy and advertising requirements.

Account Deletion

User control

Users can request account deletion inside the app from Profile > Request Account Deletion. If a user cannot access the app, they can request deletion by contacting support using the details below.

External deletion request method: Email siremondigitalsolutions@gmail.com using the subject EngRes Hub Account Deletion Request.

The request should include the email address used for the EngRes Hub account. For security, we may ask the user to verify account ownership before deleting data.

Data deleted or anonymized

  • Account profile information, including name, email, role, and account settings.
  • Saved resources connected to the account.
  • Download token records, download history, and rewarded ad progress connected to the account.
  • Resource activity connected to the account, where deletion is technically and legally appropriate.

Data that may be retained

Limited records may be retained where required or allowed for legal, security, fraud-prevention, dispute-resolution, or operational reasons. Public educational resource files uploaded by an admin are app content and are not deleted because a normal user deletes their account.
